# StyleNow - Clothing Brand Website

A modern, responsive website for a premium clothing brand built with HTML, CSS, and JavaScript.

## Features

✨ **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
🛒 **Shopping Cart** - Add products to cart with visual feedback
🎨 **Modern UI** - Clean and professional design with smooth animations
📱 **Mobile-First** - Optimized for mobile viewing experience
🔗 **Smooth Navigation** - Smooth scrolling between sections
📧 **Contact Form** - Newsletter and inquiry form

## File Structure

```
├── index.html      # Main HTML structure
├── styles.css      # Complete styling and responsive design
├── script.js       # JavaScript interactivity
└── README.md       # Documentation (this file)
```

## How to Use

1. Open `index.html` in a web browser
2. Navigate through different sections using the navigation menu or scroll
3. Click "Shop Now" or navigate to the shop section
4. Click "Add to Cart" to add products (demo functionality)
5. Fill out the contact form to send inquiries

## Customization

### Colors
Update the color scheme in `styles.css`:
- Primary: `#667eea` (Purple)
- Accent: `#ff6b6b` (Red)
- Dark: `#1a1a1a` (Black)

### Products
Edit the product cards in `index.html` to add or modify products.

### Brand Name
Replace "StyleNow" with your brand name throughout the files.
